# Changes

## 1.1.0 — 5 November 2026

- Enlarged the site-wide type scale. Main body copy uses 16–18 px at the default browser scale; metadata, source notes and footer links are generally 14–16 px. Sizes use `rem` and respect browser text scaling.
- Replaced the split homepage hero with a full-width photo stage. The introductory text and calls to action now sit below the carousel.
- Replaced postcard tilts with smooth horizontal/depth movement. Every photo stays upright, and the selected photo is flat in front. Frames are slim, and captions/credits sit below the photos.
- Added navy backgrounds with light text to the photo stage, research section, featured PI card, instrument visuals and contact panels. Other sections use white or pale blue with restrained circular line decorations.
- Added small hover transitions and one-time entrance animations without adding dependencies. Reduced-motion users receive static transitions; slideshow playback remains opt-in.
- Preserved the six main sections, editable content, relative GitHub Pages paths, filters, source information and booking link configuration.

## 1.0.0 — 4 November 2026

- Initial complete static website with six primary sections, documented public sources and modular content.
